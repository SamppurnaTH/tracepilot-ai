# Same model, with and without TracePilot

Both systems use `muse-spark-1.3`, the same sandbox, logs and basic tools. Every patch is applied to a fresh copy and judged by **hidden acceptance tests** (`eval/hidden/`) that neither system sees. A *false success* is a run that claimed the problem was fixed when the hidden tests say it wasn't. Generated by `backend/scripts/compare.py` from `eval/comparison.json`.
